

| 結局名稱 | 聲音設計建議方向 |

|---|---|

| 安心夜歸路 | 腳踏車鏈條轉動聲、輕柔的車流背景音、偶爾的蟲鳴，整體節奏平穩，沒有壓迫感，呼應移動安全帶來的踏實感 |

| 被好好照顧的街角 | 鳥鳴、灑水聲、長輩低語聊天聲，音量偏小、節奏很慢，呈現一種被照顧、不急不徐的安心感 |

| 越熱鬧，越想家 | 咖啡廳杯盤碰撞聲、人群交談的嗡嗡聲，底層混入一段不明顯的搬家貨車或紙箱拖拉聲，熱鬧底下藏一點不安 |

| 方便，但有點貴 | 自行車鈴聲跟咖啡店點餐聲交疊，背景偶爾出現房屋仲介廣播或招租傳單翻動聲，呈現便利跟代價同時存在的曖昧感 |

| 照顧得太好的代價 | 修剪植栽的園藝工具聲、灑水聲，混入遠處房屋仲介帶看的交談片段，呈現「被照顧」跟「被重新定價」的連動 |

| 平凡但安穩的日常 | 風吹過樹葉聲、遠處小孩玩耍聲、規律的腳步聲，整體乾淨、沒有特別突出的音效，呼應它「沒有故事性」的平靜 |

| 什麼都做了一點，卻沒人記得 | 多種城市環境音混在一起但音量都壓得很均勻，刻意不讓任何一種聲音突出，呈現面面俱到卻沒有記憶點的模糊感 |

| 那年夏天，我們蓋了一個沒人下水的池子 | 水波輕微晃動聲跟蚊子嗡嗡聲交替出現，中間穿插一段空蕩的回音，呈現荒廢泳池的寂靜跟諷刺感 |

| 滑出去容易，滑進日常很難 | 電動平衡車滑行的電子嗡鳴聲、路人驚呼或閃避的短促聲響，節奏忽快忽慢，呈現混亂跟不協調感 |

| 效果圖很美，現實很安靜 | 玻璃帷幕被風吹過的低頻聲、空蕩大樓裡的回音，幾乎沒有人聲，呈現野心十足卻空無一人的落差感 |
