# housing_points.geojson

GeoJSON FeatureCollection，共 909 個 Point feature，每個 feature 代表一筆台南市東區或南區的房地產交易紀錄（geocoding 失敗的 102 筆已排除）。

properties 欄位：

┌────────────────┬──────────┬─────────────────────────────────────────────────────────────────────────────────────┐
│      欄位      │   型態   │                                        說明                                         │
├────────────────┼──────────┼─────────────────────────────────────────────────────────────────────────────────────┤
│ type           │ string   │ 建物型態：透天厝 / 住宅大樓 / 華廈 / 公寓                                           │
├────────────────┼──────────┼─────────────────────────────────────────────────────────────────────────────────────┤
│ color          │ string   │ 對應顏色 hex：透天厝 #3B82F6（藍）、住宅大樓 #F97316（橙）、華廈                    │
│                │          │ #22C55E（綠）、公寓 #A855F7（紫）                                                   │
├────────────────┼──────────┼─────────────────────────────────────────────────────────────────────────────────────┤
│ percentile     │ float    │ 該筆交易的建物單價（總價/建物坪數）在全體 1,011 筆中的百分位排名                    │
│                │ 0–1      │                                                                                     │
├────────────────┼──────────┼─────────────────────────────────────────────────────────────────────────────────────┤
│ price_per_ping │ float    │ 每坪價格（新台幣元）                                                                │
├────────────────┼──────────┼─────────────────────────────────────────────────────────────────────────────────────┤
│ district       │ string   │ 行政區（東區 / 南區）                                                               │
├────────────────┼──────────┼─────────────────────────────────────────────────────────────────────────────────────┤
│ address        │ string   │ 原始地址（全形）                                                                    │
└────────────────┴──────────┴─────────────────────────────────────────────────────────────────────────────────────┘

用途： 用 L.geoJSON() 建立點位圖層，依 color 欄位著色，hover 時顯示 percentile 與 price_per_ping。

# housing_heat.js

載入後暴露全域變數 housingHeatData，內容為 909 筆 [lat, lng, weight] 陣列。

- lat / lng：地址 geocoding 結果（WGS84）
- weight：同 percentile，範圍 0–1，代表該筆交易的房價相對強度

用途： 直接傳給 Leaflet.heat：

L.heatLayer(housingHeatData, {
  radius: 25,
  maxOpacity: 0.7,
  gradient: { 0.4: 'blue', 0.7: 'yellow', 1.0: 'red' }
}).addTo(map)

---
注意事項：
- 少數點位座標落在廊道範圍外（geocoding 誤判，例如 23.3x 緯度），接進地圖後視覺上會看到離群點，可在 Leaflet 加 bounds 過濾


## 計算方式

### 1. 單價（每坪單價）

```
單價 = 總價 / 建物移轉坪
```

- 單位：元 / 坪
- 建物移轉坪為 0 的資料會被過濾掉

### 2. 百分位數（percentile）

```
percentile = 低於本筆單價的交易筆數 / 全部有效交易總筆數
```

- 值域：0.0（最低單價）到接近 1.0（最高單價）
- 這個值同時作為熱力圖的強度（intensity / weight）
- 百分位愈高，代表相對房價壓力愈大，熱力圖顏色愈深

範例：若 1,011 筆中有 800 筆單價低於本筆，則 percentile = 800 / 1011 ≈ 0.791

### 3. 地理編碼（Geocoding）

- 使用 Google Maps Geocoding API
- 輸入：`台南市{地址}`（自動加前綴）
- 輸出：`[lat, lng]` 座標
- 快取存在 `geocode_cache.json`，重複地址不會再呼叫 API
- 每次呼叫之間有 0.1 秒延遲，避免超過 API 頻率限制
- 無法取得座標的地址會被略過（不進入輸出檔案）

## 輸出格式

### housing_points.geojson

GeoJSON FeatureCollection，每筆交易一個 Feature：

```json
{
  "type": "Feature",
  "geometry": {
    "type": "Point",
    "coordinates": [經度, 緯度]
  },
  "properties": {
    "type": "住宅大樓",
    "color": "#F97316",
    "percentile": 0.8032,
    "price_per_ping": 353651.5,
    "district": "東區",
    "address": "崇慶街一段９２號八樓之２"
  }
}
```

型態顏色對照：

| 型態 | 顏色 |
|---|---|
| 透天厝 | `#3B82F6`（藍） |
| 住宅大樓 | `#F97316`（橘） |
| 華廈 | `#22C55E`（綠） |
| 公寓 | `#A855F7`（紫） |

### housing_heat.js

Leaflet.heat 格式的 JavaScript 陣列，直接在 `<script>` 中載入：

```js
const housingHeatData = [
  [緯度, 經度, 強度],  // 強度即 percentile，0.0 ~ 1.0
  ...
];
```

前端用法（搭配 Leaflet.heat）：

```js
L.heatLayer(housingHeatData, { radius: 20 }).addTo(map);
```
