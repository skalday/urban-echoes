# Urban Echoes

一個以台南鐵路綠廊道為題的卡牌小遊戲。
玩家必須在每個政策事件中，選擇不同的綠園道治理方向，每次選擇會讓民眾產生對應的輿論反應，形成最終測驗結果。

## 特色

1. 以真實社群資料與人口統計為基礎，由 AI Agent 模擬不同族群的輿論回饋
2. 遊玩結束後提供 prompt，讓你可以繼續和 AI 深入討論政策
3. 測驗結果頁提供對應聲景，讓不同政策結局以城市環境音呈現

## 設計流程

以綠廊道周邊行政區（東區、中西區、北區、南區）的戶政事務所人口統計掌握初步人口結構，輔以社群媒體爬蟲抓取的評論資料，以及 Claude Opus 針對不同年齡層、性別與都市環境議題所生成的深度研究報告，建立各 Agent 的性格輪廓 JSON。再以性格 JSON 結合周邊環境圖資，設計遊戲事件與流程。
