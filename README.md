# Urban Echoes 都市的聲音

一個以台南鐵路綠廊道為題的政策模擬卡牌遊戲。玩家在六個政策節點中，於有限資源下選擇不同的綠園道治理方向，每個選擇會即時影響四種居民與輿論角色的觀感，最終匯聚成十種不同的政策結局，並以對應的城市環境音呈現。

## 這是什麼

「都市的聲音」採用 policies shape politics 的概念設計：政策不是單純回應既有民意，而是會在執行過程中創造新的受益者、受影響者與反對聲音。玩家不是在選「正確答案」，而是在六個面向（都市願景、景觀設計、景觀維護、交通政策、交通設計、房價政策）做出取捨，每個選擇都有對應的資源成本，最終會走向十種不同的政策結局。

## 玩法說明

- **六個政策節點**：都市願景、景觀願景、景觀維護、交通政策、交通設計、房價政策，每局皆有四個選項（三張正經選項、一張荒謬選項）
- **資源限制**：總資源上限為 15，正經選項 cost 1 到 3，荒謬選項 cost 10，選了等於賭一把，後面幾層幾乎只能選最便宜的選項
- **四種角色即時反應**：每次選擇後，輿論報導、青年短居學生、青年在地居民、高齡在地居民會分別產生期望度變化與短評
- **三個隱藏判定軸，分別對應三個族群的核心價值觀**：移動安全對應短居學生的通勤與夜間安全需求、維護信任對應高齡居民對「被認真照顧」的感受、仕紳化壓力對應在地青年面對商圈活力與居住排擠的矛盾
- **十種結局**：選中荒謬選項即直接觸發對應的荒謬結局（游泳池、電動平衡車、賽博龐克大樓三條故事線）；若沒選荒謬選項，則比較三軸分數，依單軸最高、兩軸同分、三軸全平分出七種結局，確保所有牌卡組合都有對應結局

十種結局的觸發機率經窮舉模擬全部組合計算，從最容易出現的「越熱鬧，越想家」（仕紳化壓力最高，約 57%）到最稀有的荒謬結局（約 0.1% 到 0.4%）都有，機率僅供參考，遊玩體感仍以實際試玩為準。

## 都市的聲音：結果頁聲景設計

因應「都市的聲音」這個專案命名，結果頁不只顯示分數與文字結局，更把政策結果轉譯成對應的城市環境音。完成六層政策牌局後，玩家可以親自播放屬於自己選擇的城市聲景，例如景觀公園型結局是樹葉與鳥聲，房價壓力過大的結局則是施工聲與密集車流聲。聲音在這裡不是操作回饋，而是政策結果的感官化呈現。

結果頁同時提供：

- 政策路線與結局稀有度
- 四種角色的最終態度
- 可直接複製的 AI 討論 prompt，方便玩家把自己的選擇路徑帶到 ChatGPT、Claude 等工具上延伸討論
- 社群分享文案（Threads / X / Facebook / Instagram）

## 資料依據與設定流程

本專案以台南鐵路綠廊道周邊行政區（東區、中西區、北區、南區）的真實人口統計與網路輿論資料為基礎，建立四種角色的性格輪廓。目前累積的資料規模：

| 類別 | 資料項目 | 資料量 |
|---|---|---:|
| 輿論 | 新聞報導（近一年 Google 新聞搜尋） | 23 篇 |
| 輿論 | Threads 評論（Python 爬蟲蒐集） | 164 筆 |
| 輿論 | Facebook 評論（Python 爬蟲蒐集） | 253 筆 |
| 輿論 | 關鍵字組合（Google Trends、YouTube） | 52 筆 |
| 人口 | 成大、台南大學在學學生數（114 學年） | 29,461 人 |
| 人口 | 15-64 歲人口（東區、中西區、北區、南區） | 335,860 人 |
| 人口 | 65 歲以上人口（同上四區） | 107,009 人 |
| 環境 | 房屋交易資料（內政部實價登錄） | 約 1,011 筆 |
| 環境 | 行道樹分布圖資（台南市政府工務局） | 約 38,344 個點位 |

資料時間範圍大致對應 2025 年 6 月至 2026 年 6 月。四種角色的設計流程分兩階段：先把新聞、社群評論與人口統計彙整成一份涵蓋各年齡層、身分與家庭組成對環境因子關係的研究報告，再依此建立四份 BDI（beliefs、desires、intentions）角色設定檔，分別定義每個角色對城市議題的信念、核心期望與政策反應傾向，最後轉換成遊戲內的事件規則與短評文字。輿論報導角色直接對應新聞與社群評論資料，三種居民角色則對應各自的人口統計基礎。

## 技術說明

本專案為無 build step 的純靜態網站，使用 HTML、CSS 與原生 JavaScript 實作，可直接以 GitHub Pages 部署。目前角色反應與結局判定皆採用靜態規則，尚未串接 LLM；地圖圖層目前為示意資料，後續可串接行道樹圖資、房價交易資料與交通節點資料，呈現更貼近現實的政策訊號。

## 注意事項

本專案為課堂展示與 MVP 原型，角色反應是根據資料整理後設計的模擬，不代表真實市民、媒體或任何機構的立場，不應被解讀為真實民調。
